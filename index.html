Introduction

This is a test project developed for demonstrating the Proof of Concept showcasing Meta Lead Ads integration using webhooks , React Native App and real time refreshing backend for an Online Assessment.

Information Requested

This form is a simple Contact Us form that requests for test user's email and full name.

How We Use This Information

  • Meta sends a webhook notification containing the leadgen_id.
  • The Backend uses that ID to request the actual lead details from Meta's Graph API.
  • The Backend then sends the retrieved lead to the React Native app so the UI updates automatically.
